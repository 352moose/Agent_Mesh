# OPERATOR DESK

The human's inbox. Agents deliver here — reports, notes, briefs — typed files per the RULEBOOK desk protocol, same frontmatter and naming as any seat desk. Read what lands, flip it to `sweep` when absorbed; the sweep clears it like any other desk. This README keeps the shelf alive through packaging.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop.

```
── Tour Stop — WORKSPACE/OPERATOR_WORKSPACE/DESK/

Welcome to your desk — the one inbox in the mesh that belongs to you.
When an agent finishes something you should see — a report, a brief, a
note — it doesn't paste it into chat and hope; it delivers a typed,
dated file here, in the same format as anything on an agent's desk.
Your side is simple: read what lands, and when you're done, clear it
whichever way you like — drag the file into the trash's sweep folder
yourself, or just change the small status line at the top to "sweep"
and the housekeeping pass carries it away on its own. Either door
works; that's what keeps this a live inbox instead of a pile. If a
file is sitting here, it's waiting on you.

One more thing, for those of you who run an always-on agent — the
kind that lives on a server, wakes on a clock, and works while you
sleep. If you have one, this desk is where it should drop its
reports. Any outside agent that can write a file can deliver here:
same typed, dated format, straight into this folder, and its work
joins the mesh's paper trail — you read it, flip it to sweep, and
the housekeeping carries it away like anything else. The mesh
doesn't care whether a report came from a seat you fetched or a bot
you left running somewhere — if it's addressed to you, it lands on
this desk.
```
