# TOOLS

Hand-run utilities, installed and owned by the user. Two shelves: SCRIPTS (Python source staged by agents) and COMMANDS (installed executables). Anything that runs on a clock belongs in `../CRONS/`, not here.

---

── Tour Stop — WORKSPACE/OPERATOR_WORKSPACE/TOOLS/

This is the tools room — home for utilities you run by hand, as
opposed to CRONS next door, where jobs run on a clock. Two shelves
