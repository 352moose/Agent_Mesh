| Rule                                                                                       |
| ------------------------------------------------------------------------------------------ |
| One `##` block per idea — what it is, why it appeals, what would make it worth starting    |
| Capture during the conversation, never from an end-of-session recall pass                  |
| Riffing commits to nothing — no project is stood up from this file unless the user says so |
| An idea that becomes a project moves into that project's own docs; leave a pointer behind  |
| Nothing is pruned on age — a cold idea costs one block                                     |
