# PROJECTS

> The primary workflow home — one folder per project, four tiers by state. Each tier's README carries its own rules; this card covers the whole layer in one tour turn.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers all four tiers — the walk does not stop at each tier folder.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/PROJECTS/

Welcome to PROJECTS — this is where the real work lives. Every build
gets its own folder, and the folders sort into four rooms by how
alive they are. ACTIVE is the workbench: list it and you're looking
at everything being built right now. PARKED is the shelf — projects
you paused on purpose, kept whole and ready, waiting for nothing but
your word. SIDE_QUESTS is the junk drawer in the best sense:
experiments, little tools, the thing you tried for a day — detours
that travel light, and graduate to ACTIVE if they grow real legs.
And the GRAVEYARD is where finished stories rest — every ended
project kept whole and readable, because this workspace never burns
its own history. Projects move between rooms as whole folders;
nothing here ever gets deleted. Open any project folder and the same
handful of files repeat, in the same places — that sameness is what
lets a seat pick up a build it has never seen before.
```
