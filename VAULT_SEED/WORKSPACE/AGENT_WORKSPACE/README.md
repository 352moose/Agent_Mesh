# AGENT_WORKSPACE

The agent system's root. `AGENTS/` holds the machinery (BOOTSTRAPS, RULES, DESKS, MEMORY_CARDS, TEMPLATES), `REFS/` the per-seat reference shelves, `PROJECTS/` the work (ACTIVE, PARKED, SIDE_QUESTS, GRAVEYARD). This README exists so the tour has a card here.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/

You're standing in the engine room — this is where the agent team
lives and works. AGENTS holds the machinery: each seat's standing
instructions, its inbox, and the memory it carries between sessions.
REFS is the team's reference shelf, one section per seat. PROJECTS is
where the actual work happens — active builds, parked ideas, side
quests, and a graveyard for what didn't pan out. You're always welcome
in here, and the projects especially are worth watching — but day to
day this room runs itself. The team lives here; you visit.
```
