# PROTOCOLS

The mesh's procedure shelf — one folder per seat. A protocol is a step-by-step procedure a seat loads and runs on demand (never from memory, never freehand); it lives here, not in the seat's boot, so the boot stays lean and the procedure stays canonical. Templates are blank forms to copy; protocols are instructions to run — the two shelves are siblings, not the same thing.

Currently shelved: `OVERSEER/New_agent_build.md` — the procedure for adding a new seat to the mesh. Empty seat folders are ready shelves, not omissions.
