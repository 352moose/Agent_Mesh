# RULES

The mesh rulebook — shared operating rules every seat loads at startup.

---

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — AGENTS/RULES/

One file lives here, and every seat reads it before doing anything
else: the rulebook.

It is the shared half of how this place works. A startup file says who
a seat is; the rulebook says how all of them behave — how memory gets
kept and trimmed, how a file is labelled when it's sent to another
seat, what things are named and why, how one seat hands work to
another. It is deliberately short and written as rules rather than
prose, because it is read in full at every startup and length costs
attention.

If two seats ever seem to disagree about procedure, this is the file
that settles it, and the Overseer is the seat that changes it.
```
