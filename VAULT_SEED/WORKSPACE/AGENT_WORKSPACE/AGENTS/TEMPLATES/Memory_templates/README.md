## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — AGENTS/TEMPLATES/Memory_templates/

Two blank forms, one for each kind of memory a seat keeps.

The session form is the scratch pad — a seat writes to it as things
happen, so nothing depends on remembering at the end what mattered in
the middle. The standing form is the card a seat carries between
sessions: patterns it has noticed, decisions that still bind, a short
log.

Both carry their own rules at the top, including how much they are
allowed to grow. That limit is the point. Memory that is allowed to
grow forever stops being memory and becomes a transcript.
```
