# MEMORY CARDS

The mesh's memory room — three tiers (SESSION scratch, STATIC archive, ACTIVE carry-forward), one folder per seat per tier. Discipline lives in the RULEBOOK memory table and each file's own rules. This README carries the memory stop's system card.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/AGENTS/MEMORY_CARDS/

This is the memory room — how the team remembers between sessions.
Each seat keeps three layers here, one folder per seat on each
shelf. SESSION_MEMORY is the notebook for the session happening
right now; when a session closes, those notes are distilled into
one dated card and the notebook is wiped clean. STATIC_MEMORY is
the shelf those dated cards land on — the seat's history, one card
per closed session. ACTIVE_MEMORY is the small living card a seat
reads first at every spin-up: what still matters, carried forward
and trimmed as it goes. The seats maintain all of it themselves —
none of it is homework for you. One exception: CLIde keeps no
shelves here at all — just a single active card that lives inside
each project, right beside the code it's about.
```
