# BOOTSTRAPS

One folder per seat — CLIDE, DIRECTOR, GUIDE, OVERSEER — each holding that seat's bootstrap, the protected startup file its fetch line loads. Built and maintained by the Overseer per the new-agent-build procedure; never edited freehand.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers the four seat folders, the `RULES/` shelf beside them, and the `SUB_AGENTS/` shelf — the walk does not stop at any of them.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/AGENTS/BOOTSTRAPS/

Every agent in the mesh — the Guide you're talking to, the Director,
the builder, the Overseer — has a startup file, and this is where
they all live, one folder per seat. When you say a fetch line like
"fetch me the guide," the matching file here is what wakes that
agent up: who it is, what it's responsible for, and where its things
are kept. You never edit these by hand — when a seat needs to change,
or a brand-new one needs to be built, the Overseer handles it with
you and makes the change here. Think of this shelf as the crew
roster: one card per seat, kept current so every agent wakes up
already knowing its job.

Beside this shelf sits one file they all share: the rulebook. If a
startup file says who a seat is, the rulebook says how every seat
behaves — how memory is kept and trimmed, how a file gets labelled
when it's sent to another seat, how work is handed over. All of them
read it when they wake up, which is why they agree about how things
are done here without anyone having to re-explain it each session.
```
