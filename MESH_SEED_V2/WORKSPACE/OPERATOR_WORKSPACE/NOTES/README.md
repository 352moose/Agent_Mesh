# NOTES

User notes. Generalized in function — anything worth keeping lands here — but identical in format: one file per note, named and fronted exactly alike.

Filename: `NOTE_YYYY-MM-DD_NN.md` — NN is the note tally within that date (first note of the day = 01).

Frontmatter seed, top of every note:

```markdown
---
type: note
created: YYYY/MM/DD
title:
---
```

This README keeps the empty shelf alive through packaging.
