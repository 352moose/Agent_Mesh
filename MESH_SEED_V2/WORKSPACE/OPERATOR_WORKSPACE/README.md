# OPERATOR_WORKSPACE

The human's rooms. `DESK/` is the operator's inbox, `NOTES/` their scratch shelf, `ARCHIVE/` cold storage in four shelves, `CRONS/` the scheduled jobs' room (empty until the Overseer's first setup session stages them), `TOOLS/` utilities run by hand. Agents stage into these rooms; they never install, schedule, or delete here. This README exists so the tour has a card here.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers all five rooms — the walk does not stop at each.

```
── Tour Stop — WORKSPACE/OPERATOR_WORKSPACE/

This half of the workspace is yours. The agents have their own rooms
next door; these are your things, and no seat maintains any of it
unless you ask. There are five. Your desk, where an agent delivers
anything you should actually read. Your notes, scratch space with one
format and no rules past it. The archive, four shelves of cold storage
for what has earned keeping. The automation room, where scheduled jobs
are staged for you to install and own. And the tools room, for
utilities you run by hand.

The split is deliberate and it runs one way: agents stage things here
and you decide what happens next. Nothing gets installed, scheduled,
or deleted on your behalf. If you only ever open one room in this
workspace, make it the desk — that is where the mesh talks to you when
you are not in the chat.
```
