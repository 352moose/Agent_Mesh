# BACKUPS

Manual backup space — the user dupes folders into here as backup, on their own cadence. Nothing automated touches it.

*A cron could take this job on user request — optional, not blocking.

This README keeps the empty shelf alive through packaging.

── Tour Stop — WORKSPACE/OPERATOR_WORKSPACE/ARCHIVE/BACKUPS/

BACKUPS is the simplest shelf in the archive. When you want a safety
copy of something, you duplicate the folder in here yourself, on

agent writes to it and no sweep clears it, so a copy stays exactly as
