# SUB_AGENTS — OVERSEER

The Overseer's spawnable helpers. Holds `RELAY.md` — one instance per slice during a cascade, applying a single named correction and reporting its diffs back.

---

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — AGENTS/SUB_AGENTS/OVERSEER/

The Overseer's helpers, and at the moment there is one: a relay.

It exists for a specific problem. When something has to change the
same way across forty files, one seat working down the list gets
worse as it goes — the fortieth file gets less attention than the
first, and by then the correction has quietly drifted from what it
started as. So the Overseer splits the list, hands each slice to a
fresh relay, and every file gets a first-file level of care.

The relay is deliberately narrow. It is told exactly which files, and
exactly one kind of change, and it may do nothing else. If it meets
something ambiguous it stops and reports rather than deciding. Each
one comes back with the changes it made, and the Overseer reads every
one of them before any of it stands.
```
