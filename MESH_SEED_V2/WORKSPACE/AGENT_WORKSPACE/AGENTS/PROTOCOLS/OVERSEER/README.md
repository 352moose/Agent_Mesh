# PROTOCOLS — OVERSEER

Maintained by the Overseer. See the shelf README for what a protocol is. Cascade procedures live in `CASCADES/`, the new-seat build procedure in `BUILD/`.

---

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — AGENTS/PROTOCOLS/OVERSEER/

The Overseer's shelf, and the fullest one — this is the seat that
maintains the workspace, so most of what it does has a written
procedure behind it.

Most cluster around one problem: changing something that other things
point at. Renaming a file, moving a folder, altering a shape across a
whole class of documents — each has its own procedure, because each
breaks differently. There is one for patching a protected file, which
begins by staging a copy, because the copy is the undo. There is one
for handing slices of a large job to helpers, so a change lands on
the fortieth file as carefully as on the first. And there is one for
building a brand-new seat from scratch, so the roster can grow
without the new arrival missing a piece.

You won't run these. But if you ever wonder why a rename here doesn't
leave broken links scattered behind it, this shelf is the answer.
```
