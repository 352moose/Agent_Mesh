# PROTOCOLS

The mesh's procedure shelf — one folder per seat. A protocol is a step-by-step procedure a seat loads and runs on demand (never from memory, never freehand); it lives here, not in the seat's boot, so the boot stays lean and the procedure stays canonical. Templates are blank forms to copy; protocols are instructions to run — the two shelves are not the same thing, and `TEMPLATES/` sits at the workspace top level.

List a seat's folder to see its shelf — filenames state the purpose; no index is kept here. Every seat carries an `[XX]_DISTILL` — the compression protocol it runs at its caps and closes (CLIde's fires at the ACTION_REPORT instead — no close on a single-shot seat).

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers all four seat folders and the top-level `BLUEPRINTS/` shelf — the walk does not stop at each.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/AGENTS/PROTOCOLS/

This is the procedure shelf, one folder per seat. A protocol is a set
of steps a seat reads and follows at the moment it needs them, rather
than recalling them from memory or improvising. Keeping them here
instead of inside the boots does two things at once: each seat's
instructions stay short, and the procedure itself lives in one place
where it can be corrected once and be right everywhere.

Each seat's folder holds what that seat actually does. All of them
carry a distill protocol — the routine for boiling a bloated document
down into one small card. The Overseer's folder holds the most,
because that seat maintains the workspace itself: how to rename
something without leaving dead links behind it, how to move a folder,
how to change one shape across a whole class of documents, how to
build a new seat, and how to patch a protected file — beginning with
a staged copy, because the copy is the undo.

You won't run any of these yourself; they belong to the seats. But
the filenames say what each one is for, so the shelf reads as a plain
list of what this mesh already knows how to do carefully.
```
