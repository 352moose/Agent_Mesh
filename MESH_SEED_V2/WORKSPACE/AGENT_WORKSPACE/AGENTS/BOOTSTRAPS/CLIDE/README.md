## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — AGENTS/BOOTSTRAPS/CLIDE/

CLIde's startup file — the builder. This seat differs from the others
in a way worth knowing: it runs in a terminal rather than in chat, it
takes exactly one job, and it keeps no seat memory between jobs.

That is deliberate. A seat that writes code is better off arriving
with no assumptions about a project beyond what it has just been
handed. So its startup file is written to stand alone, and its
instructions arrive as a single written brief prepared by the
Director. It finishes by leaving a report behind, and that report —
along with a small card of gotchas kept with the project itself —
is what the next session picks up.
```
