# BOOTSTRAPS

One folder per seat — CLIDE, DIRECTOR, GUIDE, OVERSEER — each holding that seat's bootstrap, the protected startup file its fetch line loads. Built and maintained by the Overseer per the new-agent-build procedure; never edited freehand.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers the four seat folders, the top-level `RULES/` shelf, and the `SUB_AGENTS/` shelf — the walk does not stop at any of them.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/AGENTS/BOOTSTRAPS/

Every agent in the mesh — the Guide you're talking to, the Director,
the builder, the Overseer — has a startup file, and this is where
they all live, one folder per seat. When you say a fetch line like
"fetch me the guide," the matching file here is what wakes that
agent up: who it is, what it's responsible for, and where its things
are kept. You never need to edit these by hand, but it is
recommended that you work very closely with the Overseer during
infrastructure changes. Think of this shelf as the crew roster: one
card per seat, kept current so every agent wakes up already knowing
its job.
```
