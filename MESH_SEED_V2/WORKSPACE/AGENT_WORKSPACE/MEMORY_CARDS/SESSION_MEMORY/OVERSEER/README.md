# SESSION MEMORY — OVERSEER

Overseer's session scratch. `CURRENT_SESSION_OVERSEER.md` is the live notebook, distilled into a static card and cleared at close — discipline lives in the file's own rule table.

---

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/MEMORY_CARDS/SESSION_MEMORY/OVERSEER/

This is the Overseer's session notebook — scratch notes on whatever
workspace care is underway right now. While the Overseer works, it
notes things as they happen: what it checked, what it fixed, what it
flagged for later. These notes aren't built to last — when the
session closes, they get distilled into one dated summary card that
lands on the Overseer's archive shelf, and the notebook is wiped
clean for the next session. An almost-empty notebook means the last
session closed the way it should. Mid-session, it's the live record
of the work.
```
