A cron's thin binding is its installation — no piece logic here.

Scope declaration: the script installs onto the tree's scheduled shelf — the one folder holding every unattended job, its name declaring it scheduled — and writes only into desk rooms and trash buckets: its own tree's by derivation, any listed foreign tree's by declaration.

The binding is one crontab line: hourly tick, absolute interpreter, quoted absolute script path, stdout and stderr appended to the shelf's log for this job. The crontab belongs to the operator; agents stage, install from the regenerated source, and verify with `crontab -l`. The scheduler — not any agent — holds whatever access grant a foreign tree requires.
