This build's home is the tree's scheduled shelf: scripts run, logs record, the install file installs. The shelf is dropped into the tree it owns — its placement declares the indexed root, so the shelf moves as one folder plus a crontab repoint. Break during the build → filed to `AGENT/GOTCHAS/[ROOM]/`, never at the end. Artifacts never mix with source.
