A cron's thin binding is its installation — no piece logic here.

Scope declaration: the script installs onto the tree's scheduled shelf — the one folder holding every unattended job, its name declaring it scheduled — and writes exactly one file outside the shelf: the tree root's `MASTER_INDEX.md`.

The binding is one crontab line: daily tick offset from siblings, absolute interpreter, quoted absolute script path, stdout and stderr appended to the shelf's log for this job. The crontab belongs to the operator; agents stage, install from the regenerated source, and verify with `crontab -l`.
