# AGENT_WORKSPACE

The agent system's root. `AGENTS/` holds the seat machinery (BOOTSTRAPS, DESKS, PROTOCOLS, SUB_AGENTS). Beside it sit the shared shelves — `RULES/` the standards every seat follows, `MEMORY_CARDS/` the memory each seat carries between sessions, `TEMPLATES/` the blank forms, `BLUEPRINTS/` the build constraints for the machines that run here — plus `REFS/` the per-seat reference shelves and `PROJECTS/` the work (ACTIVE, PARKED, SIDE_QUESTS, GRAVEYARD). `TRASH/` holds what's been swept, `STASIS/` what's frozen. This README exists so the tour has a card here.
