## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers the whole shelf — the walk does not stop at each form.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/TEMPLATES/

This shelf holds the blank forms the mesh stamps new things from.
When a new agent gets built, a new project gets opened, or a fresh
memory file gets started, nothing is improvised — an agent copies
the matching template from here and fills it in, so everything new
is born matching everything that already exists. Among them: a form
for building a new agent, a folder-shaped one for starting a project,
blanks for memory files, and a scaffold for long-lived documents.
You'll never need to fill one of these in by hand. The template
provides the source of truth, the agent provides the content that
fills it.
```
