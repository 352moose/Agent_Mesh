# TEMPLATES — Memory templates

Blank form — copied to create a new one, never edited in place as though it were live.

---

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — TEMPLATES/Memory_templates/

Three blank forms, one for each kind of memory a seat keeps.

The session form is the scratch pad — a seat writes to it as things
happen, so nothing depends on remembering at the end what mattered in
the middle. The active form is the card a seat carries between
sessions: patterns it has noticed, a short log. The static card is
the roll-up a session leaves behind at close: decisions that still
bind, facts the next instance cannot re-derive.

The living forms carry their own rules at the top, including how much
they are allowed to grow. That limit is the point. Memory that is
allowed to grow forever stops being memory and becomes a transcript.
```
