# TEMPLATES — Project template

Blank form — copied to create a new one, never edited in place as though it were live.

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — TEMPLATES/PROJECT_template/

The blank shape of a project — copied whole every time a new one
starts.

Inside are the files a project needs before it needs them: the state
of play, the brief the builder works from, the report that comes back,
and the codebase maps — the list of features wanted, the list of
small fixes wanted, the list of known bugs. Three folders: one for
the work, one for the building seat's own memory card, and one for
reference material like a requirements document.

Because every project has this shape, any seat can open one it has
never seen and know where to look. Every project this mesh will ever
hold gets stamped from this form, starting with yours.
```
