## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — TEMPLATES/PROJECT_template/REFS/

The reference half of the blank form — where a new project's
requirements document lives, alongside three empty shelves for
archive material, equations, and research.

The requirements skeleton ships blank, because the requirements are
the one thing no template can supply. The empty shelves ship anyway
so that the split between reference material and working material
exists from a project's first day, rather than being introduced later
once the two have already been mixed together.
```
