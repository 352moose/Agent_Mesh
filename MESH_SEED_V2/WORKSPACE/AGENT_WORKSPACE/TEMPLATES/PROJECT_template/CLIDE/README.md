## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — TEMPLATES/PROJECT_template/CLIDE/

The blank memory card the building seat gets for a new project. It
carries the shape and none of the content: headings, the rules for
keeping the page, and the small label block at the top marking it
as that seat's own.

A fresh copy travels with every project. That is what lets the
builder keep detailed notes on one build without dragging them into
the next.
```
