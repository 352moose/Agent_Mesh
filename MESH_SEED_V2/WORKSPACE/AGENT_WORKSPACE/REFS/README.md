# REFS

One reference shelf per seat — the standing documents an agent reads from, as opposed to the memory cards it writes for itself. Each seat folder here carries a Dive Card describing what that particular shelf holds.

Shelf fixtures are `review_status: protected`; the sweep never touches them. Each shelf's page rules live on its own README.

---

## Tour Card

> Guide: deliver the fenced block verbatim at this tour stop. This one card covers all four shelves — the walk does not stop at each.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/REFS/

This is the reference wing — one shelf per seat. A shelf holds the
standing documents an agent works from, as opposed to the memory
cards it writes for itself: research it has absorbed, baselines it
checks against, references built once and used for months.

There are four, one for each seat. The Guide's carries the running
picture of you and the vault. The Director's carries the security
checklist for the surfaces you actually work on, and the ideas you
have not committed to yet.
The Overseer's collects what it learns keeping the workspace
consistent, and CLIde's holds what one build teaches that the next
build will need.

Most of them start empty and fill as the seats work, and everything
on them is protected — the sweep that clears desks never touches a
shelf. You will rarely open one yourself, but what a seat tells you
usually traces back to something sitting here.
```
