# RULES

The mesh rules shelf — shared operating rules every seat loads at startup. Holds `RULEBOOK.md`, `CONVENTIONS.md`, `PROPERTIES.md`, and `TABLES.md`.

---

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/RULES/

Four files live here, and every seat reads the rulebook before doing
anything else.

They are the shared half of how this place works. A startup file says
who a seat is; this shelf says how all of them behave. The rulebook
holds the operating rules — how memory gets kept and trimmed, how one
seat hands work to another. Conventions says what things are named
and why. Properties says how a file is labelled — the same seven
fields on every document. Tables says what shape a table may take.
Each is deliberately short and written as rules rather than prose,
because rules get read in full and length costs attention.

If two seats ever seem to disagree about procedure, this is the shelf
that settles it, and the Overseer is the seat that changes it.
```
