# GRAVEYARD

> Projects that ended. They rest here whole — the mesh never deletes its history.

| Rule |
|---|
| Retire = move the whole project folder here, docs intact — what was learned stays readable |
| Nothing in this folder is swept, trimmed, or deleted; a resurrection (rare) moves the folder back out |

## Dive Card

> Guide: not a walk stop — deliver the fenced block verbatim only when the user takes the dive option at the shelf fork.

```
── Tour Stop — WORKSPACE/AGENT_WORKSPACE/PROJECTS/GRAVEYARD/

Projects that ended, kept whole.

Nothing is deleted here — an ended project rests with its documents
intact, including the decisions that led nowhere. That's deliberate:
the most useful thing an ended project leaves behind is the record
of why it ended, and that record only helps if it's kept whole.

It's also a fossil shelf: the files keep whatever conventions were
current when they were written, and nobody goes back to modernize
them. Read them as history, not as an example to copy.
```
